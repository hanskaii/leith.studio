# Introduction

Tanflare is a modern full-stack starter built on Cloudflare Workers and TanStack.

## Features

- **Edge-Native Performance**: Built on Cloudflare Workers.
- **Type Safety**: Powered by TanStack Router and Hono.
- **Authentication**: Integrated with Better Auth.
- **Billing**: Built-in Dodo Payments integration.
