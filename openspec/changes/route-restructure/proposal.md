## Why

The app currently has two parallel layouts (`_app` for members/creators, `_admin` for admin pages under `/s/*`), plus several dead routes (`/chat`, `/creator/$id`, `/studio/review`) that will be replaced by a unified `/studio` workspace. This sprawls the navigation, duplicates layout logic, and makes role-based UX harder to reason about. Consolidating everything under a single `_app` layout with role-guarded routes flattens the mental model and prepares the ground for the upcoming `/studio` file-management UI.

## What Changes

- **REMOVED** routes: `/chat`, `/creator` (index), `/creator/$id`, `/studio/review`, `/s/overview`, `/s/users`, `/s/events`
- **MOVED**: `/s/users` → `/users`, `/s/events` → `/events`, `/s/overview` content folds into `/overview` as the admin branch
- **MODIFIED** `/overview`: single route, content branches by role — admin sees the existing `/s/overview` dashboard; creator sees an empty placeholder (real creator overview is out of scope, deferred)
- **REMOVED** `_admin` layout — `apps/web/src/routes/(app)/_admin/` directory is deleted entirely; all formerly-admin routes move into `_app` with `Gate.assert("admin:access")` in `beforeLoad`
- **MODIFIED** sidebar — admin-only items (`/users`, `/events`) are conditionally rendered when `session.user.role` is admin
- **BREAKING** all previous `/s/*` URLs return 404; any bookmark, deep link, or external reference is broken

## Impact

- **Routes**: `apps/web/src/routes/(app)/_admin/` directory deleted; `apps/web/src/routes/(app)/_app/` gains `users/`, `events/` subdirectories; `overview/`, `chat/`, `creator/`, `studio/review/` deleted from `_app/`
- **Generated route tree**: `apps/web/src/routeTree.gen.ts` regenerated by TanStack Router plugin
- **Sidebar config**: `apps/web/src/routes/(app)/_app/route.tsx` `MENU_CONFIG` gets an `"admin"` entry
- **Authorization**: each migrated admin route adds `Gate.assert("admin:access", { actor: session.user })` in `beforeLoad`
- **No backend changes** — API routes are unchanged
- **No database changes**
